# 连接器接入契约草案

当前无真实接入。每个适配器须提供以下契约并由受控样例验证；字段含义未确认前不得启用生产回写。

| 项目 | 必填内容 |
|---|---|
| 身份 | 服务商、账号、商户、仓/店/站点、API版本、权限范围 |
| 数据职责 | 库存实物/订单承诺/履约/退款的权威来源及字段包含关系 |
| 事件 | event_id、business_action_id、entity_id、entity_version、occurred_at、received_at、payload |
| 快照 | snapshot_id、covered_watermark、snapshot_at、库存状态及原始字段；无水位显式null |
| 查询 | 按我方业务编号查询外部建单/取消/出库状态；区分不存在、处理中、成功、失败、未知 |
| 回写 | 比较数量/版本条件、幂等键、绝对值权威限制、SKU/仓串行顺序 |
| 限流 | 配额、分页稳定性、重试等待提示、授权过期处理 |
| 安全 | 验签、敏感字段最小化、凭据服务端保存、日志脱敏 |
| 异常 | 联系人、服务时段、撤回未确认处理、人工接管格式 |

事件去重键由商户+连接账号+源event_id组成，业务动作另设唯一关联，不以名称或收到消息的时间代替源标识。库存余额仅通过领域事务修改，适配器不得直接写余额表。

API返回200不等于库存撤回或取消已完成，必须得到业务确认。无可靠水位不允许自行推断快照已覆盖哪些出库；无查询能力的超时建单禁止盲目重建。外部能力不足时保留未知状态并停止新增不可信承诺。

真实验收需订单、取消竞争、实际出库、退货、库存回写、重复/迟到回执、快照对账及未知结果查询八类证据。模拟适配器只证明内部接口可调用，不能把连接状态设置为正常。
